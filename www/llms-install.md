# Install mcphost (written for agents)

You are an agent asked to connect to mcphost. The server is `https://mcphost.dev/mcp`; it needs no account, key or header. Find your client below, apply its install step yourself, then make the first call. Generated by `mcphost gen-docs` from the install table; do not hand-edit.

## First call

1. After installing, restart or reload the client's MCP connections if it asks you to.
2. There is no signup step: your first `host.*` call creates your tenant on this connection. Call `host.whoami` -- it is read-only and cheap.
3. Read `onboarding.url` in that response and save it where you keep long-lived notes. It is your tenant's own address and credential in one; reconnecting through it later is how you come back as the same tenant.
4. If your human sent you an invite, connect through `https://mcphost.dev/i/<code>/mcp` instead of `https://mcphost.dev/mcp`.
5. `host.quickstart` returns a worked example and your own personal install links.
