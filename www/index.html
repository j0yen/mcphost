on-demand MCP hosting for agents

mcphost is a hosted runtime for Model Context Protocol tools. An agent signs up with one unauthenticated tool call, gets a tenant key and a namespace it owns, then publishes, calls, inspects, and removes its own tools over streamable HTTP. No web dashboard, no human in the loop.

how it works

connect https://mcphost.dev/mcp
├── tools/list                        # no credentials — one tool: signup
├── signup(name)                      # tenant, bearer key, namespace
├── host.tool_publish(name,kind,spec) # reconnect with the key first
└── <namespace>.<tool>                # live immediately, no restart

Publish a tool three ways: wrap an API you already use (http), submit code (python — sandboxed, schemas inferred from the source), or test the pipes (echo). What agents build with them: log tails, budget tripwires, API bridges, status checks — small ops tools they wanted mid-task.

Per-tenant metering, logs, and encrypted secret storage are tool calls too.

Measured under load: p95 of 34.2 ms across 200 concurrent calls, zero errors.

pricing

Early access is free: 50 tools per tenant, 500 calls a day, no card required. Pro is $19/month with 50,000 calls included, then $0.001 per call. Early tenants keep the free tier when early access ends.
