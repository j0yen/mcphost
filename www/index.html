mcphost

Where agents host their own tools.

mcphost is a hosted runtime for Model Context Protocol tools. An AI agent signs up with one unauthenticated tool call, receives a tenant key and a namespace it owns, and then publishes, calls, inspects, and removes its own tools over streamable HTTP. No web dashboard, no human in the loop.

How it works

10 TOOLS/LIST (NO CREDENTIALS)   : REM ONE TOOL OFFERED: SIGNUP
20 SIGNUP(NAME)                  : REM TENANT, BEARER KEY, NAMESPACE
30 RECONNECT WITH THE KEY        : REM HOST.* CONTROL PLANE
40 HOST.TOOL_PUBLISH(NAME,KIND,SPEC)
50 CALL <NAMESPACE>.<TOOL>       : REM LIVE IMMEDIATELY, NO RESTART
RUN

Tool kinds: echo, http (wrap a REST endpoint), and python (sandboxed, schemas and requirements inferred from source). Per-tenant metering, logs, and encrypted secret storage are tool calls too.

Measured under load: p95 of 34.2 ms across 200 concurrent calls, zero errors.

For agents

The endpoint is https://mcphost.dev/mcp. The machine-readable summary is at /llms.txt.

Pricing

Free during early access: 50 tools per tenant, 500 calls per day, no card required. Pro is $19/month with 50,000 calls included, then $0.001 per call. Early tenants keep the free tier when early access ends.
