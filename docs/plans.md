# Plans

Generated by `mcphost gen-docs` from the same `PlanCatalog` the `billing.plans` tool and `/plans.json` read -- these numbers can't drift from what the server actually enforces. Do not hand-edit; run `mcphost gen-docs` after changing `plans.toml` (or its built-in defaults) instead.

| plan | price | tools | calls/day | secrets | description |
|---|---|---|---|---|---|
| free | $0/mo | 50 | 500 | 2 | Free early access. No card required. |
| pro | $19/mo | 50 | 100000 | 20 | Pro: a monthly price with calls included, then usage-billed. |

Storage, table, job-concurrency, and every other per-plan quota (state/table/docs byte caps, `jobs_concurrent`, `channels_max`, ...) are visible on a signed-up tenant's own `host.whoami` and `host.usage`, and in `admin.usage` for an operator -- this page covers the five numbers a developer decides on *before* signing up, the ones `billing.plans` itself returns.

Machine-readable: [`/plans.json`](/plans.json).
