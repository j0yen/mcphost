## Archive layout

Every `host.export` archive is a `.tar.gz` of exactly these entries, and `host.import` accepts exactly these. Generated from `export::ArchiveEntry`.

| path | host.import |
|---|---|
| `manifest.json` | read first: version, per-entry sha256 and bytes, tool kinds |
| `tools/<name>/v1/config.json` | re-published through host.tool_publish |
| `tools/<name>/v1/source` | counted; the source is inside config.json |
| `state/<key>.json` | restored with host.state.set |
| `documents/<id>.json` | history only, not restored (docs/ is) |
| `secrets.txt` | names reported as secrets_to_set, never values |
| `runs.jsonl` | history only, not restored |
| `threads.jsonl` | history only, not restored |
| `usage.json` | history only, not restored |
