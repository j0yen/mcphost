# Upstream connections

Generated by `mcphost gen-docs` from `providers.toml` -- do not hand-edit; add a provider by adding a block to `providers.toml`. `host.connect.providers` lists these providers with `available: true|false` (a provider is available once the host has both its client id and client secret in the environment).

## `github`

- authorize: https://github.com/login/oauth/authorize
- token: https://github.com/login/oauth/access_token
- refresh: `none`
- client id env: `MCPHOST_CONNECT_GITHUB_CLIENT_ID`
- client secret env: `MCPHOST_CONNECT_GITHUB_CLIENT_SECRET`
- callback: `/connect/github/callback`
- docs: https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/scopes-for-oauth-apps

| scope | purpose |
|---|---|
| `repo` | Read and write code, issues and pull requests in private and public repositories |
| `read:user` | Read the user's profile |
| `user:email` | Read the user's email addresses |
| `read:org` | Read organization membership |
| `gist` | Create and read gists |

## `google`

- authorize: https://accounts.google.com/o/oauth2/v2/auth
- token: https://oauth2.googleapis.com/token
- refresh: `offline_access`
- client id env: `MCPHOST_CONNECT_GOOGLE_CLIENT_ID`
- client secret env: `MCPHOST_CONNECT_GOOGLE_CLIENT_SECRET`
- callback: `/connect/google/callback`
- docs: https://developers.google.com/identity/protocols/oauth2/scopes
- authorize param: `access_type=offline`
- authorize param: `prompt=consent`

| scope | purpose |
|---|---|
| `https://www.googleapis.com/auth/spreadsheets.readonly` | Read Google Sheets |
| `https://www.googleapis.com/auth/spreadsheets` | Read and write Google Sheets |
| `https://www.googleapis.com/auth/drive.readonly` | Read files in Google Drive |
| `https://www.googleapis.com/auth/drive.file` | Read and write only the Drive files this app creates or opens |
| `https://www.googleapis.com/auth/gmail.readonly` | Read Gmail messages |
| `https://www.googleapis.com/auth/calendar.readonly` | Read Google Calendar events |

## `notion`

- authorize: https://api.notion.com/v1/oauth/authorize
- token: https://api.notion.com/v1/oauth/token
- refresh: `none`
- client id env: `MCPHOST_CONNECT_NOTION_CLIENT_ID`
- client secret env: `MCPHOST_CONNECT_NOTION_CLIENT_SECRET`
- callback: `/connect/notion/callback`
- docs: https://developers.notion.com/docs/authorization
- authorize param: `owner=user`

No scope names; access is granted by the user at authorization time.

## `slack`

- authorize: https://slack.com/oauth/v2/authorize
- token: https://slack.com/api/oauth.v2.access
- refresh: `rotating`
- client id env: `MCPHOST_CONNECT_SLACK_CLIENT_ID`
- client secret env: `MCPHOST_CONNECT_SLACK_CLIENT_SECRET`
- callback: `/connect/slack/callback`
- docs: https://api.slack.com/scopes

| scope | purpose |
|---|---|
